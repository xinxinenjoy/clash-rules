# ——— Loon 节点筛选备份（NameRegex / FilterKey）· 2026-11-02 ———
# 用法：把「组名」下面那行正则整段粘进 Loon 的 FilterKey；icon 行只作配色参考，不用粘。
# 各组共用同一个「信息行拦截」前缀（模板，不要单独用）：
#   ^(?!.*(?:\b(?:0\.\d+|\d+\.\d+|[2-9]\d*)\s*[xX×倍]\b|\b[xX×]\s*(?:0\.\d+|\d+\.\d+|[2-9]\d*)\b|流量|剩余|用量|到期|过期|重置|套餐|包月|年付|\d+\s*(?:G|T|天|月)\b)).*(<国家关键词>).*
#
# 四条约定：
# 1) 0.1 倍率节点是主动排除的，不是漏配（低倍率多有限速/超售），别顺手删掉这一段。
# 2) 短国家码（HK/US/SG/DE…）一律写成 (?:^|[^A-Za-z])XX(?![A-Za-z]) —— 前后不能紧挨英文字母。
#    否则 RUSSIA→美国、UKRAINE→英国、FRANKFURT→法国、DENVER→德国、CALIFORNIA→加拿大，全部串组。
#    CN 额外写成 (?![A-Za-z0-9])，避免「CN2 GIA」线路名把美国节点也拖进中国组。
# 3) 大小写都列了（HK|hk，不靠引擎的 (?i)），换机场不至于因为大小写就掉组。
# 4) 尺寸/流量判定结尾有 \b：没有它，「CN2 GIA」里的「2 G」会被当成流量信息，整个节点被踢出所有组。
